# 三分钟全流程演示脚本

分镜排期总时长为 **180 秒**；成片按以下累计时间点切换，并在导出后核对实际时长。演示对象是完整 Agent 工作台：前七段呈现需求、取材、生成、报价入口、海报与核验导出，最后一段查看完整应用和作品材料入口。静态成果页用于阅读与下载。

[完整应用入口](https://a1211joy-huawei-pc-agent-app.ms.show)已发布，云端接口全流程与实际重启恢复已有实测记录。浏览器登录的证据来源为用户实际网页登录确认“已进入工作台”，不扩展为全部云端按钮均已完成自动化端到端验证。本脚本可在已登录在线实例录制；长等待可明确标注加速或回放已保存的真实云端结果。本地案例与云端接口记录仍分别标注，GitHub 未发布、Dify Cloud 未联调。

录屏前准备：

- 录屏前使用工作台凭证登录在线实例，确认指定 ima 库及所需模型连接正常。准备已保存的真实云端文章、海报与审核记录。需要回放本地成果时，明确标为本地来源，不能把本地截图或接口响应标成在线 UI 截图。
- 准备一个不完整输入的新任务，以及真实成果的任务/版本回放。对话过程可现场操作；长时间模型调用使用已有实际生成结果或明确剪辑加速。切换时显示“实际生成结果回放”，加速时显示“等待过程已加速”，保留原始录屏。
- 关闭“连接与设置”、开发者工具、终端、系统通知和其它私有窗口；使用不显示本机用户名的展示画面。检查画面、地址栏、文件路径与声音中均不出现 API Key、Client ID、工具 Token、登录凭证或本机用户名。
- 预先打开最终导出文件，并核对完整应用、成果展示与 GitHub 仓库的实际状态。完整应用当前标注“已发布／云端接口与重启恢复已实测／用户实际网页登录确认通过”；GitHub 未发布时只展示源码本地 README 和待发布状态，不显示不存在的仓库链接。确认浏览器下载路径不暴露私人信息。
- 保留“价格待确认”“发布标识待确认”与 AI 背景说明，不为画面整洁删掉真实待确认项。不要将后端直连模型或本地模式说成 Dify Cloud 已完成联调。
- 每段按下列时间点切换；口播结束后的余量留给点击、停留和展示。逐字稿合计约 600 个汉字，不朗读操作和检查点。

## 00:00–00:18｜18 秒：从不完整需求开始

**屏幕操作：** 在已登录的在线工作台新建任务，输入“帮我写一篇华为电脑软文”，展示实际追问。若模型等待较长，明确标注等待加速，或切到已保存的真实追问记录并显示“云端真实结果回放”。

**口播逐字稿：**

> 这是华为PC图文工作台，面向门店导购和内容运营。我先输入一句不完整需求。助手不会直接堆参数，而是追问目标人群、使用任务和发布平台，把创作要求整理成可以继续编辑的需求卡。

**证据检查点：** 本地界面与云端不完整任务接口已真实触发追问。浏览器登录由用户实际确认；录制中的新建任务、多轮操作按现场实际结果核对，不预先标为全部控件已通过。

## 00:18–00:40｜22 秒：补全场景与选购问题

**屏幕操作：** 补充“杭州，大学新生开学季，比较选型，HUAWEI MateBook 14 鸿蒙版，公众号，预算 6000 元，关注鸿蒙和 WPS”。展示需求卡；模型等待时可切真实已完成任务，切换前显示“实际生成结果回放”，不把既有任务当作这次新输入的即时结果。

**口播逐字稿：**

> 这次面向杭州的大学新生，为MateBook十四鸿蒙版制作公众号内容，预算六千元，重点关注鸿蒙和WPS。系统记录人群、开学场景与比较选型阶段，并把预算保留为用户自述条件，不把它当成产品售价。

**证据检查点：** 本地和云端接口案例保留实际输入条件；未确认 WPS 功能完整度及专业软件适配，不表述为已适配。

## 00:40–01:00｜20 秒：查看 ima 事实和原图

**屏幕操作：** 打开“资料与图片”，展示指定知识库名称与连接状态，展开一个事实来源及对应产品原图；不打开凭证设置。

**口播逐字稿：**

> 右侧是指定ima共享库的事实和原图。每条事实关联准确型号、资料标题和来源，配图也保留说明与插入位置。这里核对的是鸿蒙版，不能把相近型号混用；资料不能确认的软件适配，会继续列为待确认。

**证据检查点：** 本地文章引用 4 条事实及 3 张原图；云端检索得到 13 条事实，文章实际引用 4 条、选择 3 张原图。两组来源分别标注，连接权限不等于独立 ima 账号身份认证。

## 01:00–01:25｜25 秒：文章生成与人工修改

**屏幕操作：** 在在线工作台展示公众号生成入口、DeepSeek 模式与真实稿件。可使用已保存的云端案例，其改稿标题为“大学新生选电脑：先看课程、携带与软件需求”；演示人工修改、保存并重开，核对内容。新生成需等待返回或标注加速；使用既有结果时持续显示回放标识。

**口播逐字稿：**

> 这是DeepSeek实际生成的文章，围绕携带、屏幕和课程软件展开。标题、导语、正文、配图和咨询引导可以预览。我再人工调整标题并保存，重新打开仍是保存后的内容；不满意的修改，也可以取消或查看历史版本。

**证据检查点：** 本地图形编辑的保存、取消、重开已实测；云端 DeepSeek 生成、修改保存、重新读取及复制接口也已实际成功。不能由接口通过推定浏览器操作通过。

## 01:25–01:48｜23 秒：搜索价格线索与规则报价入口

**屏幕操作：** 打开“报价方案”，展示真实 DeepSeek Search 的线索及未核实状态；既有搜索记录标注回放。打开报价录入入口，指示商家、SKU、商品状态、来源、时效与资格字段。本例只展示规则报价的输入入口与证据要求，不填写虚构报价，不展示或声称得到了实际最低价计算结果。

**口播逐字稿：**

> 联网搜索复用DeepSeek凭证，返回价格或活动线索。线索不能直接当成交价。报价要补齐商家、SKU、成色、时效和资格，再由独立规则引擎计算；这次没有核实到手价，所以不会编造优惠或最低价。

**证据检查点：** 本地与新增云端 Search 各自实际返回 12 条未核实线索；云端空报价接口保持无最低价结论。引擎有独立边界测试，不代表七渠道结算价均已接通。

## 01:48–02:14｜26 秒：转换海报，背景与产品分层

**屏幕操作：** 切换在线任务的门店海报版本，显示短标题、三个以内卖点、到店引导和主视觉。背景生成等待可加速，或明确回放已保存的真实云端结果；旁列 ima 原图、Qwen-Image 背景及核验记录。海报文件与界面画面分别说明，不以本地图片代替云端 UI 截图。

**口播逐字稿：**

> 同样的人群和产品，转成海报后改为短标题、三个以内卖点和到店引导。这里回放实际生成结果：Qwen-Image只生成背景，产品主体仍是ima原图，由程序按比例独立贴层，避免模型重画产品。成品也保留AI背景说明。

**证据检查点：** 本地与云端均已实际生成 Qwen-Image 背景并贴合 ima 原图；云端视觉 passed=true、渲染 verified=true。实际重启后任务和成品哈希保持一致；浏览器与人工成品仍需验收。

## 02:14–02:41｜27 秒：核验与文件交付

**屏幕操作：** 在在线实例展示通过项和待确认项，演示文章导出及海报 PNG/PDF 导出，下载后实际打开检查。若使用已有本地文件回放或云端接口记录，标明来源；不把 HTTP 200 或哈希记录说成浏览器已经下载打开。

**口播逐字稿：**

> 交付前可以看到事实、图片、营销表达、语义和视觉检查。绿色通过项与价格、发布标识的待确认项同时保留。文章可导出含图片的压缩包，海报可导出PNG和PDF；这些文件已经实际下载并打开检查，便于继续人工复核。

**证据检查点：** 本地成品已实际下载打开；云端文章四格式与海报 PNG/PDF/JSON/报告接口返回成功，视觉与渲染通过。价格及发布标识仍待确认，浏览器下载打开另行验收；PDF 为单页位图。

## 02:41–03:00｜19 秒：完整应用与作品材料

**屏幕操作：** 先展示完整应用地址及已登录的工作台，再切成果展示页和说明书。浏览器登录状态注明来源为用户实际网页登录确认，云端接口与重启恢复另有实测记录。GitHub 未发布时只展示源码 README 本地预览及待发布状态，不打开私有配置。

**口播逐字稿：**

> 完整应用已发布，浏览器登录已由用户实际确认。云端接口与重启恢复均有实测记录；成果页保留案例，说明书说明复现步骤。源码待发布，Dify待联调，凭证不公开。

**录制检查点：** 完整应用、本地案例、云端接口及用户实际网页登录确认分别留档。登录进入不代表全部按钮自动化端到端已通过，录制操作按实际结果验收。GitHub 未发布、Dify 未联调、最低价无结论保持一致。
