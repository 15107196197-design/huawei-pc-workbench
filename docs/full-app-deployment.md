## 登录与账号边界

1. 部署者在自己的电脑打开[完整应用发布页](http://127.0.0.1:8791/)。本机发布工具运行并验证魔搭授权后，会显示“在线工作台登录账号”。
2. 复制登录名和工作台密码并自行保存，再打开上方完整应用地址登录。发布令牌与工作台密码用途不同，工作台登录页不填写魔搭 Token。
3. 不把实际密码、魔搭令牌、API Key 或 ima Client ID 放进仓库、说明书、录屏或聊天。公开文档不附实际登录凭证。

工作台是单操作人版本，使用相同登录账号的授权操作者共享任务和历史，尚未提供多租户隔离、每人独立空间或账号权限管理。登录后的“当前账号”表示工作台身份；ima 连接状态另外核对指定知识库的权限，不把两者混为同一个认证结果。

登录采用 HTTPS 下的会话 Cookie，不依赖平台保留的 `Authorization` 请求头。容器重启会清除内存中的登录会话，需要重新登录；这不代表任务和文件被删除。注销会撤销当前会话。发布工具关闭后无法从密码哈希恢复原始密码，因此应先在本机保存凭证；需要变更时，由部署者更新平台私有登录配置。

浏览器操作使用上方 `ms.show` 应用入口或魔搭空间页面。程序化验收另走平台返回的 API 专用入口，使用平台令牌及工作台会话两个独立的认证层；不把该专用入口当作匿名分享页，也不把平台令牌填进工作台登录表单。API 登录已通过，浏览器登录另由用户实际网页登录确认通过；全部控件的浏览器操作不因这两项通过而自动视为通过。

## 首次使用

1. 点击“新建任务”，用自然语言描述产品、人群、场景与发布平台。信息不足时按对话提示补充；例如先输入“帮我写一篇华为电脑软文”，再补充大学新生、开学季、公众号、具体型号与关注的软件。
2. 核对需求卡，明确购买阶段、主要问题和内容目标。检索指定 ima 资料后检查事实、型号、来源与原图，资料冲突或无法确认的信息应先处理。
3. 生成内容并在预览中修改。切换公众号、小红书、朋友圈或海报时，按新平台重新生成，检查篇幅、结构、语气、配图数量和行动引导。编辑后保存并重新打开，确认修改已留存。
4. 需要报价时先联网查询线索，再为具体商家、SKU、商品状态、服务条件和有效期补齐可核验报价。独立规则引擎处理门槛、互斥、身份、国补与换新；搜索结果不自动成为已确认到手价。
5. 制作海报时，AI 可生成背景，产品主体保留 ima 原图并按比例合成。检查原图与型号一致性、视觉核验和成品一致性结果。
6. 核对事实、图片、合规与待确认项，再复制或导出。阻断项必须先修正；存在待复核提示时，不能忽略适用条件。应用输出供操作者核验后交付，不自动发布到营销平台。

可按[3 分钟全流程演示脚本](三分钟演示脚本.md)演示。首次演示前先完成登录，并核对本实例上游连接；模型等待时间可明确标注快进或回放真实保存结果，不能把静态样例当作当前实时生成。

云端任务保存在该空间自己的数据库，本地开发机的历史任务与私有配置不会随公开源码自动迁移。

## 私有配置与调用费用

DeepSeek、百炼与 ima 凭证只通过创空间私有 Secret 注入运行环境。公开源码、Dockerfile、前端和发布清单均不含实际凭证；云端“连接与设置”提供配置状态与连接检查，配置修改由部署者在平台处理。ima 凭证只用于已授权知识库，不依赖开发机的主目录文件。

本次发布只选择已核实的免费 Docker CPU 规格，没有部署本地大模型或购买 GPU。**CPU 资源免费不表示模型调用免费**：文本生成、联网搜索、视觉核验和背景生成仍受对应服务账号的余额、配额、计费和限流约束。服务配置有效也不能证明某个具体模型在当前地域可用，必须实际运行验证。

当前没有已确认的杭州最低到手价，也没有七个渠道的自动成交价接口。报价以输入的来源、资格和时效为准。

## 数据、持久化与恢复

服务通过 `STUDIO_DATA_DIR=/mnt/workspace/huawei-pc-content-studio` 存储 SQLite、任务版本、素材缓存、生成图片及导出文件。启动器仅初始化专属目录、`media/` 和 `generated/` 的权限，随后切换到 UID/GID 10001 运行应用。不会修改挂载根目录或用 `chmod 777` 开放数据。

平台挂载的 `/mnt/workspace` 用于跨重启保留数据。本次已实际重启并通过接口重新登录，任务 revision 15 与 PNG/PDF 成品哈希均保持一致。空间迁移、转让或重命名可能影响数据保留；重要任务与媒体应备份到部署者的私有存储。SQLite 与内存登录会话适合当前单实例部署，不支持多个独立实例共享写入。

代码或环境配置更新后需重新部署，并再次验证登录、任务恢复和上游调用。密码变化会使旧登录会话失效。连接失败、余额不足、资料冲突或核验阻断应显示明确错误或待确认状态，不能以旧结果冒充新调用成功。

## 部署复现与验收

源码部署配置位于 [`deploy/modelscope/`](../deploy/modelscope/README.md)。魔搭上传包使用该目录的 Dockerfile 作为仓库根 Dockerfile，保留核心源码、静态前端、锁定依赖和启动器；不上传本机 `.env`、`data/` 或发布令牌。Docker 资格、实名认证和可用资源以账号实际平台返回为准。

托管模式设置 `STUDIO_HOSTED=1`、`STUDIO_MANAGED_CONFIG=1`，并要求有效的工作台账号与密码哈希；缺失登录配置时拒绝启动，不能回退到无登录公网模式。`/healthz` 仅检查服务存活，不触发上游推理费用，也不证明模型已经接通。

完整验收应检查：未登录不能读取任务或发起计费操作；登录与退出；不完整需求追问；真实 ima 检索；文章生成、编辑保存与重开；报价规则；海报背景与原图合成；事实、图片和合规核验；实际导出；重启后重新登录且任务、文件仍在。Dify Cloud 回调需在同一后端单独联调，不能用直连模型的成功替代。
